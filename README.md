## Overview
Modern web portal for LumiSync Studio presenting creative multimedia projects, video production portfolios, client testimonials, and project inquiry forms.

---

## Key Features
- Showcase of commercial video production and digital design campaigns
- Interactive contact and project brief inquiry system
- Optimized video embeds and responsive media gallery

---

## Tech Stack
- **Framework**: Next.js
- **Language**: TypeScript
- **Database**: MySQL
- **Styling**: Tailwind CSS, Lucide React

## Getting Started

### Prerequisites
Make sure you have the required runtimes and tools installed on your machine:
- Node.js (v18+ recommended) / Appropriate runtime
- Git

### Installation & Local Setup
```bash
git clone https://github.com/MohammadKevin/LumiSync-Studio.git
cd LumiSync-Studio
npm install
npm run dev
```
